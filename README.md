# Kreative Center Homebrew tap

```sh
brew install --cask kreativecenter/tap/top75
```

| Cask | App |
| --- | --- |
| `top75` | [TOP75 for macOS](https://github.com/kreativecenter/top75-macos), an open-source configurator for the Darmoshark TOP75 keyboard |

Update with `brew upgrade --cask top75`. After a TOP75 release, run `scripts/cask.sh <version>` in the top75-macos repository and commit the updated cask here.
